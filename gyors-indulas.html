Adatvédelmi tájékoztatás

Ez a weboldal nem használ sütiket (cookie-kat), nem alkalmaz nyomkövetőket és semmilyen személyes adatot nem gyűjt a látogatókról.

A weboldal a GitHub Pages szolgáltatásán keresztül működik. A tárhelyszolgáltató a szolgáltatás biztonságos működtetése érdekében technikai adatokat, így IP-címeket is naplózhat. Erről a GitHub saját adatvédelmi tájékoztatója ad további információt:

GitHub General Privacy Statement

Külső hivatkozások megnyitásakor az adott weboldal saját adatvédelmi szabályai érvényesek.
